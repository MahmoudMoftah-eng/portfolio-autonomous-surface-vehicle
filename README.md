# Autonomous Surface Vehicle Simulation

## Overview
Developed a ROS 2 and Gazebo simulation environment for an unmanned surface vehicle to support localization and autonomous-navigation testing.

## My contribution
- Integrated URDF/XACRO vehicle models.
- Defined TF frames and simulated sensor interfaces.
- Supported localization and autonomous-navigation testing in simulation.
- Contributed as a member of the Best Software Team at TEKNOFEST.

## Technologies
ROS 2 · Gazebo · URDF · XACRO · TF · Autonomous Navigation

This repository is a public project case study. Team-owned source code and competition materials are not published.
